Movie Quiz – Debug Grid v37

No new player/profile is required.

- A small GRID OFF / GRID ON button is always visible while this temporary module is installed.
- Press G or click the button to toggle the grid.
- ?mqGrid=1 is optional and only auto-enables the grid.
- The grid uses the cinema master coordinate system 1672×941.
- Remove css/debug-grid.css, js/98-debug-grid.js and their two index.html references to uninstall.
