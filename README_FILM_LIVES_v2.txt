Movie Quiz – Film lives animation patch v2

Tento ZIP je overlay patch určený k nahrání do existujícího repozitáře.
Obsahuje jen soubory, které je potřeba přepsat / doplnit:

- js/29-interaction-guards.js
- assets/lives/film-life-intact.webp
- assets/lives/film-life-burned.webp

Co patch dělá:
- zachová stávající funkcionalitu 3 životů
- vizuálně ji nahradí 3 nalepenými políčky filmové pásky
- při ztrátě života spustí animaci vzplanutí / hoření a vymění asset za spálený
- nevyžaduje změnu index.html
