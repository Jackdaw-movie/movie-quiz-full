MOVIE QUIZ RESPONSIVE EXTERIOR v6.9 — REPOSITORY AUDIT

This patch was rebuilt after auditing the actual current GitHub production implementation.

ROOT CAUSES FOUND:
1. test-responsive responsive-runtime-v2.js globally disabled the production desktop booth hotspot
   with pointer-events:none!important. That broke the production desktop shoes/hover path.
2. Earlier portrait car/booth assets were crops with imperfect masks, not truly isolated assets.
3. Earlier portrait marquee implementations used a rectangular/full marquee crop. Production desktop
   does NOT do that: it uses bulb-only halo + three isolated bulb groups.

v6.9:
- desktop interaction override is portrait-only; desktop returns to production hotspot + shoes + hover
- car.png and booth.png rebuilt as real transparent cutouts
- car shine uses a true transparent alpha mask derived from rebuilt car.png
- booth hover uses an edge-only glow generated from rebuilt booth alpha
- marquee uses bulb-only portrait overlays with the exact desktop v6.3 timing architecture
- hand and bubble geometry remain unchanged
- test loader versions bumped to bypass cache
