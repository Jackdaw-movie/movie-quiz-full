Movie Quiz – Avatar onboarding stage v13

Patch navazuje na v11 a NEMĚNÍ schválený vizuální směr.
Grafika nebyla znovu generována. Schválený v11 podklad byl pouze technicky upraven:
- spodní ovládací pás posunut o 24 px doprava, aby POKRAČOVAT sedělo na středu,
- ZPĚT se posunulo současně,
- carousel: hlavní avatar cca +15 % a výš,
- boční avatary jsou menší, dále od středu a oříznuté do bočních kruhových zón,
- hover zóny přesně kopírují šipky a obě spodní tlačítka,
- ZPĚT má stejný hover princip jako POKRAČOVAT,
- zapnut avatar prefetch helper a runtime cache pro rychlejší vykreslení avatarů.

Nasazení:
1. Rozbalte ZIP do kořene současného repo movie-quiz-full.
2. Přepište stejnojmenné soubory.
3. Ostatní soubory nemažte.
4. Po GitHub Action použijte Cmd+Shift+R.
